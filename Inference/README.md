# Inference Guide

This folder contains the inference code for **Expert-Specific Large Language Models for Radiology**.

## 📋 Prerequisites

- NVIDIA GPU with CUDA support (recommended: A100, V100, or RTX 3090+)
- At least 16GB GPU memory for 3B models, 40GB for 7B models
- CUDA 12.1 or compatible version

## 🔧 Installation

```bash
git clone https://github.com/Junwen-Liu/IMIT-MedImg-LLMLF-Expert.git
cd IMIT-MedImg-LLMLF-Expert/Inference

# Create conda environment
conda create -n llmlf python=3.10.14
conda activate llmlf

# Install dependencies
pip install torch==2.1.0 --index-url https://download.pytorch.org/whl/cu121
pip install pandas==2.2.3 transformers==4.40.2
```

## 🚀 Method 1: Interactive Inference

Run interactive inference with a single model:

```bash
python chatbot.py \
    --path ./models/3b_radiologist1 \
    --token_path ./tokenizer \
    --max_new_tokens 512 \
    --device cuda:0
```

## 📊 Method 2: Batch Inference

Process multiple reports from a CSV file:

```bash
python chatbot.py \
    --path ./models/3b_radiologist1 \
    --token_path ./tokenizer \
    --max_new_tokens 512 \
    --device cuda:0 \
    --batch_size 4 \
    --in_csv ./example_gbk_input.csv \
    --out_csv ./example_gbk_output.csv \
    --new_col_name RESPONSE_3b_radiologist1
```

### Input CSV Format

The input CSV must:
- Contain a column named `INSTRUCTION` with the CT findings (including the prompt template)
- Be encoded in **GBK** format
- Use proper quoting for Chinese characters

Example Python code to prepare input:

```python
import csv
import pandas as pd

# Prepare your data
findings_list = [
    "根据下面一段上腹部CT的影像描述：肝脏大小形态正常...生成一份对应的诊断意见：",
    # ... more findings
]

df = pd.DataFrame({"INSTRUCTION": findings_list})
df.to_csv('input.csv', index=False, encoding='gbk', quoting=csv.QUOTE_ALL)
```

## ⚙️ Command Line Arguments

| Argument | Description | Default |
|----------|-------------|---------|
| `--path` | Path to the model directory | Required |
| `--token_path` | Path to the tokenizer directory | Required |
| `--max_new_tokens` | Maximum tokens to generate | 512 |
| `--device` | GPU device to use | `cuda:0` |
| `--batch_size` | Batch size for inference | 1 |
| `--in_csv` | Input CSV file path (batch mode) | None |
| `--out_csv` | Output CSV file path (batch mode) | None |
| `--new_col_name` | Column name for generated impressions | None |

## 📝 Notes

- Models are trained on **Chinese-language** abdominal CT reports
- The prompt template format is: `根据下面一段上腹部CT的影像描述：{findings}生成一份对应的诊断意见：`
- For English translation, consider using translation APIs (e.g., Google Translate, DeepL)
- Expert-specific models are optimized for individual radiologist styles and may produce different outputs for the same input
